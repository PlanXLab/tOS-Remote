# 원격 작업 공간 열기

**원격 작업 공간 열기**를 누르면 다음 순서로 진행합니다.

1. 보드 접속과 인증 확인
2. 보드 작업 공간을 PC의 로컬 작업 사본 폴더로 동기화
3. 선택한 창(**현재 창** 또는 **새 창**)에서 작업 공간 열기

열린 뒤에는:

- **터미널**: 터미널이 보드의 SSH 셸로 열립니다. 이전 세션에서 복원된 로컬 터미널은 보드 터미널로 바뀝니다.
- **동기화**: VS Code, PC의 파일 관리자, 보드 터미널에서 한 변경이 양방향으로 동기화됩니다.
- **F5**: 현재 Python 파일을 tOS에서 디버깅합니다.
- **Ctrl+F5** 또는 편집기 Run 버튼(**tOS에서 실행**): 디버거 없이 tOS에서 바로 실행합니다.
- **경로 링크**: 터미널에 출력된 `/home/tos/Workspace/...` 경로를 Ctrl+클릭하면 로컬 파일의 해당 줄이 열립니다.
- **닫기**: 패널이나 상태 표시줄의 **원격 작업 공간 닫기**를 누르면 업로드를 마친 뒤 세션을 종료합니다.

작업 공간을 닫지 않고 VS Code를 종료해도 로컬 작업 사본은 유지되고, 다시 실행하면 자동으로 이어서 연결됩니다.
