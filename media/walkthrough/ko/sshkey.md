# SSH 키 등록

SSH 키를 등록하면 다음을 비밀번호 없이 사용할 수 있습니다.

- SSH 터미널
- **Ctrl+F5**(디버그 없이 실행)와 실행 버튼
- **F5** 원격 디버깅 (키 인증 필수)

등록 과정:

1. PC에 `~/.ssh/id_ed25519` 키가 없으면 새로 만듭니다.
2. 보드 비밀번호를 한 번 입력하면 공개 키를 보드의 `~/.ssh/authorized_keys`에 추가합니다.
3. 키 인증이 되는지 확인합니다.

입력한 비밀번호는 VS Code 보안 저장소(SecretStorage)에만 저장되며 설정 파일에는 기록되지 않습니다.
