# 보드 연결 정보

사이드바의 **tOS Remote** 아이콘을 누르면 패널이 열립니다.

| 항목 | 기본값 | 설명 |
|---|---|---|
| 주소 | `192.168.254.1` | 보드 IP 주소 |
| 포트 | `22` | SSH(Dropbear) 포트 |
| 계정 | `tos` | 보드 사용자 |
| 작업 경로 | `/home/tos/` + `Workspace` | 홈 디렉터리 아래 폴더. `/home/<계정>/`은 계정으로 자동 입력되며 이후 경로만 입력합니다. 없으면 자동 생성 |
| 로컬 폴더 | (첫 연결 시 선택) | 원격 작업 공간 사본을 보관하고 동기화할 이 PC의 로컬 폴더 |

**연결 테스트**는 SSH 포트 응답과 인증 방식(SSH 키 또는 저장된 비밀번호)을 확인합니다.
