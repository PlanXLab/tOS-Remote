# 보드 연결 정보

사이드바의 **tOS Remote** 아이콘을 누르면 패널이 열립니다.

| 항목 | 기본값 | 설명 |
|---|---|---|
| 주소 | `192.168.254.1` | 보드 IP 주소 |
| 포트 | `22` | SSH(Dropbear) 포트 |
| 계정 | `tos` | 보드 사용자 |
| 작업 경로 | `/home/tos/Workspace` | 없으면 자동 생성 |
| 드라이브 | 자동 | Z:부터 비어 있는 문자 사용 |

**연결 테스트**는 SSH 포트 응답과 인증 방식(SSH 키 또는 저장된 비밀번호)을 확인합니다.
