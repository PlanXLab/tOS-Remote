# WinFsp

tOS Remote connects the board's workspace folder over SFTP and shows it as a Windows drive (for example `Z:`). **WinFsp** is required to create this virtual drive.

- The **Install** button runs `winget install WinFsp.WinFsp`. When the administrator approval (UAC) prompt appears, select **Yes**.
- If winget is not available, the official download page (https://winfsp.dev/rel/) opens.
- You only need to install it once per PC.
